## Rules

- Add a module only to an included page that is not locked, where it fits the page's topic, and only if the page does not already show the same figures.
- Additions are optional. Add nothing if the pages already cover the material movements well.
- Suggestions are things for the wealth manager to decide (for example leaving out a page that adds little for this client). Each suggestion names a page id.
- Give a one-sentence reason for every addition and suggestion, addressed to the wealth manager, and a one-sentence summary of what you did.
